# 支持矩阵

| 范围 | 状态 |
| --- | --- |
| Python snapshot validation 与 analysis | 支持，offline |
| network labeling | 支持，但不是 chain verification |
| Rust analyzer | 可选 process-boundary 组件 |
| Solidity/Vyper | 仅支持 template validation |
| live trading 与 execution | 不支持 |
| RPC、wallet 与 signing | 不支持 |
| contract compilation/deployment/audit | 不支持 |
| cross-chain bridging 与 routing | 不支持 |

`docs/en/` 英文文档是 canonical source。
